# Ogłoszenia po przejściu na wspólny model

Sekcja jest częścią jednego systemu publikacji. Stary adres /panel/ogloszenia
przekierowuje do /panel/informacje. Zachowano kolekcję announcements, identyfikatory
i podkolekcje. Szczegóły formularza, widoczności, zdjęć i migracji opisuje
[Wspólna publikacja treści](publications.md).
